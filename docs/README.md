# OctoAcme Project Management Docs

This folder contains the central process documentation for how OctoAcme plans, delivers, and improves projects.

OctoAcme follows an iterative, customer-focused delivery model with clear ownership and lightweight artifacts. Teams maintain a regular delivery rhythm through standups, weekly delivery syncs, and demos/reviews, while managing work through a board-based flow from Backlog to Done. Engineering execution emphasizes small pull requests, CI gating, and review/approval before merge.

Quality is built in through unit and integration tests, smoke testing for critical flows, and security scanning in CI. Planning and risk management rely on project one-pagers, prioritized backlogs, risk registers, and clear escalation paths. Roles are explicitly defined across PM, PdM, Developers, QA/Testing, and Stakeholders.
